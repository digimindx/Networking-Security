# نموذج OSI ونموذج TCP/IP (04-TCP/IP Model & OSI Model)

في عالم الشبكات، يوجد العديد من الشركات المصنعة للأجهزة والبرمجيات. لكي تعمل هذه الأجهزة المختلفة معاً، تم وضع معايير (Standards) ونماذج مرجعية (Reference Models) لتوحيد لغة الاتصال.

أهم نموذجين هما:
1. نموذج OSI (Open Systems Interconnection Model).
2. نموذج TCP/IP (Transmission Control Protocol/Internet Protocol Model).

---

## OSI (The OSI Model)
![[Pasted image 20260711201804.png |1024 ]]
هذا النموذج هو نموذج نظري (Theoretical Model) وضعته المنظمة الدولية للمعايير (ISO)، ويحتوي على 7 طبقات (Layers). يتم استخدام هذا النموذج لفهم كيفية انتقال البيانات.

### طبقات نموذج OSI (من الأعلى للأسفل):

1. **طبقة التطبيق (Application Layer):**
   هي الطبقة العلوية (Layer 7)، وهي الطبقة الوحيدة التي يتفاعل معها المستخدم مباشرة. توفر واجهات للخدمات الشبكية مثل البريد الإلكتروني (Email) ونقل الملفات (File Transfer).

2. **طبقة العرض (Presentation Layer):**
   هي الطبقة السادسة (Layer 6)، مسؤولة عن تحويل البيانات (Data) إلى صيغة يمكن للبرنامج فهمها، وتقوم بالتشفير (Encryption) وضغط البيانات (Compression).

3. **طبقة الجلسة (Session Layer):**
   هي الطبقة الخامسة (Layer 5)، مسؤولة عن إنشاء (Establish)، وإدارة (Manage)، وإنهاء (Terminate) الجلسات (Sessions) بين التطبيقات.

4. **طبقة النقل (Transport Layer):**
   هي الطبقة الرابعة (Layer 4)، مسؤولة عن نقل البيانات بشكل موثوق بين الأجهزة. تقسم البيانات الكبيرة إلى أجزاء أصغر تسمى (Segments)، وتتأكد من وصولها دون أخطاء.

5. **طبقة الشبكة (Network Layer):**
   هي الطبقة الثالثة (Layer 3)، مسؤولة عن تحديد المسار (Routing) الذي ستسلكه الحزم (Packets) للوصول من المصدر إلى الوجهة، وتتعامل مع عناوين الـ IP.

6. **طبقة رابط البيانات (Data Link Layer):**
   هي الطبقة الثانية (Layer 2)، مسؤولة عن نقل البيانات بين جهازين متصلين بنفس الوسيط (Media). تقسم البيانات إلى إطارات (Frames) وتتعامل مع عناوين الـ MAC.

7. **الطبقة الفيزيائية (Physical Layer):**
   هي الطبقة الأولى (Layer 1)، تعنى بالخصائص المادية (Physical) مثل الكابلات، والمنافذ (Ports)، والإشارات الكهربائية (Electrical Signals) أو الضوئية.

## TCP/IP (The TCP/IP Model)
![[Pasted image 20260711201936.png | 1024]]
هذا النموذج هو نموذج عملي (Practical Model) وهو الأساس الذي يعمل عليه الإنترنت حالياً. يتكون من 4 طبقات فقط، وهي دمج لطبقات نموذج OSI.

### طبقات نموذج TCP/IP (من الأعلى للأسفل):

1. **طبقة التطبيق (Application Layer):**
   تدمج وظائف طبقات OSI الثلاث العليا (Application, Presentation, Session). هنا تنشأ البيانات وتجهز للإرسال.

2. **طبقة النقل (Transport Layer):**
   تقوم بنفس وظائف طبقة النقل في نموذج OSI، حيث تضمن نقل البيانات بشكل موثوق أو غير موثوق (مثل بروتوكولي TCP و UDP).

3. **طبقة الإنترنت (Internet Layer):**
   تقوم بنفس وظائف طبقة الشبكة في نموذج OSI، حيث تحدد عناوين الـ IP وتقوم بعملية التوجيه (Routing) للحزم (Packets).

4. **طبقة الوصول للشبكة (Network Access Layer):**
   تدمج وظائف طبقتي OSI السفليتين (Data Link, Physical). تتعامل مع العتاد (Hardware) والكابلات وتحويل البيانات إلى إطارات (Frames) وإشارات (Bits).

## مقارنة بين النموذجين (Comparison)

| طبقة نموذج OSI | طبقة نموذج TCP/IP | الوظيفة الرئيسية |
| :--- | :--- | :--- |
| Application (7) | Application | واجهة المستخدم وتطبيقات الشبكة |
| Presentation (6) | Application | تنسيق البيانات والتشفير |
| Session (5) | Application | إدارة الاتصال (Session) |
| Transport (4) | Transport | نقل البيانات وموثوقيتها |
| Network (3) | Internet | التوجيه (Routing) وعناوين IP |
| Data Link (2) | Network Access | العناوين الفيزيائية (MAC) |
| Physical (1) | Network Access | الإشارات والكابلات |

## مفهوم التغليف (Encapsulation)
عندما يتم إرسال البيانات عبر الشبكة، تمر عبر الطبقات من الأعلى إلى الأسفل، وتقوم كل طبقة بإضافة رأس (Header) للبيانات. هذه العملية تسمى التغليف (Encapsulation).

1. **في طبقة التطبيق:** البيانات تسمى (Data).
2. **في طبقة النقل:** تضاف معلومات التحكم وتصبح (Segment).
3. **في طبقة الإنترنت:** تضاف عناوين الـ IP وتصبح (Packet).
4. **في طبقة الوصول للشبكة:** تضاف عناوين الـ MAC وتصبح (Frame).
5. **في الطبقة الفيزيائية:** تتحول الإطارات (Frames) إلى تيارات من البتات (Bits) للإرسال عبر الكابل.

عند الوصول للجهة المستقبلة، تحدث العملية العكسية وتسمى (Decapsulation)، حيث يتم إزالة الرؤوس (Headers) واحدة تلو الأخرى حتى تصل البيانات الأصلية للتطبيق.
