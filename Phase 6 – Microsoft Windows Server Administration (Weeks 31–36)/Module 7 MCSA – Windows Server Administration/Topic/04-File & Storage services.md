# Module 7: File & Storage Services
**الموضوع:** خدمات الملفات والتخزين في Windows Server

## المقدمة
يعد دور "خدمات الملفات والتخزين" (File and Storage Services) أحد أهم الأدوار (Roles) في بيئة الخوادم الحديثة. في إصدارات ويندوز سيرفر الحديثة (Server 2022)، تم توحيد إدارة التخزين والملفات لتسهيل التعامل مع البيئات المعقدة والسحابية الهجينة. يهدف هذا التدريب إلى استعراض التقنيات الأساسية، البروتوكولات، والميزات الجديدة لعام 2022.

---

## أولاً: البروتوكولات الأساسية لمشاركة الملفات (File Sharing Protocols)

تعتمد ويندوز سيرفر بشكل أساسي على بروتوكول SMB للمشاركة، ولكن هناك تقنيات أخرى مكملة:

### 1. بروتوكول SMB (Server Message Block)
هو البروتوكول القياسي في بيئة ويندوز لنقل البيانات والمشاركة في الملفات والطابعات.
*   **الإصدار الحالي:** في Windows Server 2022، يعمل النظام بشكل افتراضي على **SMB 3.1.1**.
*   **المميزات الرئيسية لـ SMB 3.x:**
    *   **SMB Multichannel:** يسمح باستخدام أكثر من بطاقة شبكة (NIC) لزيادة النطاق الترددي (Bandwidth) وتوفير التحمل للخطأ (Fault Tolerance) تلقائياً.
    *   **SMB Direct:** يستفيد من تقنيات RDMA لنقل البيانات بسرعة عالية جداً وتقليل استهلاك المعالج (CPU).
    *   **End-to-End Encryption:** تشفير البيانات أثناء النقل (In-transit) لحماية الخصوصية.
    *   **Transparent Failover:** نقل الجلسة إلى خادم آخر دون مقاطعة المستخدم إذا فشل الخادم الأول.

### 2. بروتوكول NFS (Network File System)
بروتوكول مفتوح المصدر يستخدم بشكل شائع في بيئات لينكس، ولكن ويندوز سيرفر يدعمه الآن بكفاءة عالية.
*   **NFS 4.1:** الإصدار المدعوم في ويندوز سيرفر 2022، والذي يدعم التجميع (Multichannel) والتشفير (Security).

### 3. بروتوكول FTP (File Transfer Protocol)
يستخدم لنقل الملفات بين خوادم عبر الإنترنت أو شبكات داخلية، وغالباً ما يتم استبداله بـ SMB أو أدوات السحابة في البيئات الحديثة.

## ثانياً: تقنيات التخزين (Storage Technologies)

### 1. نظام التخزين المساحي (Storage Spaces)
تقنية تسمح بتجميع أقراص تخزين فيزيائية متعددة (Physical Disks) لإنشاء مجموعة تخزين افتراضية (Virtual Disk) بمرونة عالية.
*   **Virtual Disks:** تقسيم المساحة الافتراضية إلى أقراص منطقية.
*   **Resiliency:** توفير طرق للتحمل (Parity, Mirror) لضمان بقاء البيانات متاحة في حال تعطل قرص مادي.

### 2. التخزين المباشر (Storage Spaces Direct - S2D)
تقنية متقدمة في Windows Server 2022 تسمح بتحويل مجموعة من الخوادم (Nodes) إلى "خادم تخزين واحد" عالي الأداء (Hyper-Converged Infrastructure).
*   **المميزات:**
    *   لا يحتاج إلى مصفوفة تخزين (SAN) خارجية.
    *   يوفر التكرار على مستوى القرص (Block-level redundancy).
    *   يعمل مع الذاكرة المؤقتة (Storage Cache) لتحسين الأداء.

### 3. تقنيات المشاركة الأخرى
*   **iSCSI:** يسمح بمشاركة أقراص التخزين عبر شبكة IP (SAN over Ethernet).
*   **NFS:** كما ذكرنا سابقاً، لمشاركة الملفات مع أنظمة غير ويندوز.

## ثالثاً: نظام الملفات الموزع (Distributed File System - DFS)

يستخدم DFS لتوحيد مسارات الملفات الموزعة على خوادم متعددة تحت اسم واحد موحد. يتكون من مكونين رئيسيين:

### 1. مساحات أسماء DFS (DFS Namespaces - DFS-N)
*   **الوظيفة:** تجميع مشاركة ملفات (Shares) موجودة على خوادم مختلفة تحت مسار واحد (مثلاً: `\\Company\HR` بدلاً من `\\Server01\HR`).
*   **الهدف:** تسهيل الوصول للبيانات وتسهيل نقل الملفات بين الخوادم دون توقف الخدمة.

### 2. تكرار DFS (DFS Replication - DFS-R)
*   **الوظيفة:** مزامنة الملفات تلقائياً بين عدة خوادم.
*   **الفرق عن RDR:** يستخدم تقنية (MRXS) لنقل فقط الأجزاء المتغيرة من الملفات، مما يوفر عرض النطاق الترددي (Bandwidth) والوقت.

## رابعاً: الميزات الجديدة في Windows Server 2022 (File & Storage)

بناءً على التحديثات لعام 2022، تركز مايكروسوفت على تبسيط الإدارة والربط مع السحابة:

### 1. خدمة ترحيل الملفات (Storage Migration Service)
*   **الوصف:** أداة جديدة تتيح ترحيل الملفات والتطبيقات من الخوادم القديمة (مثل Windows Server 2012 أو 2008) إلى Windows Server 2022.
*   **الميزة:** تقوم الأداة تلقائياً باكتشاف التبعيات (Dependencies) وتثبيت الأدوار المطلوبة (Roles & Features) في الخادم الجديد، مما يقلل من وقت التوقف (Downtime) بشكل كبير.

### 2. تكامل Azure Files (Azure File Sync)
*   **الوصف:** يسمح بمزامنة ملفات الخادم المحلي (On-premises) مع **Azure Files**.
*   **الفائدة:** إنشاء "تخزين سحابي" محلي (Tiering)، حيث تبقى الملفات الساخنة (Frequently accessed) محلياً، وتنتقل الملفات الباردة (Cold data) إلى السحابة تلقائياً لتوفير التكلفة.

### 3. تحسينات SMB 3.1.1
*   دعم **SMB Direct** بشكل أفضل عبر شبكات 25GbE أو 100GbE.
*   تحسينات في الأمان ضد هجمات (SMB Relay Attacks).

## خامساً: الأمان وإدارة الملفات (Security & Management)

### 1. التشفير (Encryption)
*   **BitLocker Drive Encryption:** تشفير القرص بالكامل لحماية البيانات في حالة سرقة الجهاز.
*   **EFS (Encrypting File System):** تشفير ملفات ومجلدات محددة للمستخدمين، بحيث لا يستطيع أي مستخدم آخر فتح الملف حتى لو كان لديه صلاحيات قراءة.

### 2. التعداد القائم على الوصول (Access-Based Enumeration - ABE)
*   ميزة في مشاركة الملفات (SMB Share) تمنع المستخدمين من رؤية المجلدات التي ليس لديهم حق الوصول إليها. يظهر للمستخدم فقط ما هو مسموح له برؤيته.

### 3. حدود التخزين (Quotas)
*   السماح لمسؤول النظام بفرض حدود على حجم الملفات التي يمكن للمستخدم تخزينها في مجلد معين، لمنع امتلاء الخادم.

### 4. بنية تصنيف الملفات (File Classification Infrastructure - FCI)
*   تسمح بتطبيق سياسات (Policies) على الملفات بناءً على محتواها (مثلاً: تصنيف الملفات التي تحتوي على كلمات مثل "سري" أو "مالية" وتشفيرها تلقائياً أو نقلها لمجلد آمن).

## ملخص الدورة (Summary)

في نهاية هذا الـ Module، يجب أن يكون المتدرب قادراً على:
1.  تمييز الفرق بين تقنيات التخزين (Storage Spaces, S2D, iSCSI).
2.  تطبيق بروتوكول SMB 3.1.1 مع تفعيل الميزات الأمنية مثل التشفير و SMB Multichannel.
3.  استخدام DFS Namespaces و DFS Replication لتوحيد وإدارة الملفات.
4.  الاستفادة من "Storage Migration Service" في ترقية الخوادم القديمة.
5.  فهم كيفية ربط التخزين المحلي مع السحابة باستخدام Azure File Sync.
